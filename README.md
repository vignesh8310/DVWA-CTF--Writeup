
## Overview
This repository provides a full DVWA lab walkthrough designed for educational purposes. It demonstrates practical web security skills in a safe, isolated environment and includes step-by-step guides for the following modules:
- SQL Injection (Low, Medium, High)
- Reflected XSS
- Stored XSS
- Command Injection
- File Inclusion (LFI/RFI)
- CSRF & Broken Authentication


## Contents
- `lab-report.md` — detailed walkthrough with steps, payloads, evidence placeholders, and mitigation strategies
- `.gitignore` — recommended ignores for sensitive files and local configurations
- `screenshots/` — folder to place captured images from the lab
- `assets/` — optional scripts, payloads, or helper files used in the lab


## Getting Started
1. Clone this repository.
2. Set up a DVWA lab using Docker or a VirtualBox/VM environment with host-only networking.
3. Place screenshots in `/screenshots/` and edit `lab-report.md` with your specific details and evidence.
4. Follow the step-by-step walkthrough in `lab-report.md`.
